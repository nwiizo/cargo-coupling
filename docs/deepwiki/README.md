生成後、概要図のCDN依存、境界文書のHTTPメソッド・公開パス、設計資料へのリンクを補いました。この目次は生成後に追加しています。[実行記録](../litho-run.md)に、使用モデル、入力範囲、コードとの照合、元の生成結果にあった不足を残しています。生成文全体の動作保証や、Webの実行検証を済ませた文書ではありません。

再実行はリポジトリのルートから行います。ローカルに追加したCodex接続が必要です。

```sh
rtk proxy deepwiki-rs -c litho.toml -p . -o docs/deepwiki --target-language ja
```

再生成すると本文への補足は上書きされます。実行記録を参照し、入力やコードが変わった範囲を照合してください。現在の仕様を確認するには、既存の[設計分析資料](../design-analysis.md)と対象コードも併せて使います。

Lithoの実行統計は[短い要約](__Litho_Summary_Brief__.md)と[詳細](__Litho_Summary_Detail__.md)にあります。「完了率」は内部データの生成状況であり、コードや文書の正確さを測る値ではありません。トークン・費用の欄もCodexの利用明細ではなく、Litho側の推定です。最終ログの全工程時間は3794.04秒で、要約内の時間は出力工程の終了前に集計されています。
